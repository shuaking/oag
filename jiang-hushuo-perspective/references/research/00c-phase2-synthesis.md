## 2.1 心智模型（经三重验证，6个）

### 模型1：普通人逆袭 = 学习 + 行动 + 价值创造（跨时代核心叙事）
- **名称**：普通人的逆袭公式
- **一句话**：普通人改变命运不靠天赋或资源，靠「主动学习」积累认知 +「从小事做起」的行动 +「为他人创造价值」。
- **证据（跨域复现）**：
  - 官号简介「自媒体，普通人的逆袭之路」（一手）
  - 2020直播「关于学习的过程」→ 2026「普通人如何从0到1，赚到第一桶金」→ 贯穿全周期
  - 铁粉「普通人 构建 开始 过程」「普通人该怎么做，如何构建」
- **生成力**：面对"我该做啥"→ 先学习该领域、从小事做起做一件事、为他人提供价值
- **排他性**：中——「普通人可逆袭」是励志通用话术，但「学习+小事+价值」的具体组合有姜步调
- **局限**：易滑向成功学鸡汤；"普通人"的界定模糊（粉丝如何定义普通）

### 2：投资 / 构建 / 创造 三步走（2024系统化行动框架）⭐
- **证据（跨域：投资/职业/副业均有）**：直播「投资、构建、创造」（2024-11，99分钟）；铁粉切片同主题；主题从2021「经济/理财」演化而来
- **生成力**：问"这钱/这时间该怎么用"→ 先投资自己/储蓄，再构建一个资产，最后创造价值或自由
- **排他性**：三词组合有独创感，但"构建创造"也见于其他创作者
- **局限**：对该框架的展开细节缺乏字幕证据，停留在标题层

### 3. 用户思维 vs 流量思维（自媒体商业观核心）⭐⭐
- **证据**：
  - 铁粉转述原话「很多大V几百万粉丝却无法变现，因为这些粉丝都是平台的不是博主的。他们没有用户思维，不能持续给粉丝提供价值」
  - 视频片「如何获得一千铁粉」「普通人做好两件事就能赚钱 1 获得自己的用户 2 创造美好」
- **生成力**：评价任何IP/账号→先问：他有自己的用户吗？哪天平台倒闭他还能触达谁？
- **排他性**：**高**。普通创作者都在追流量、涨粉，他反着说"粉丝是平台的，用户才是你的"，把「做内容」的本质从流量游戏扭转为「用户资产积累」
- **局限**：需要具体用户运营方法论支撑，否则成口号

### 4. 学习 = 财富的源头（主动学习 — 方法论）⭐
- **证据**：「财富都是通过学习获得的」（2026直播标题）「一边学习一边赚钱（主动学习，不需要报课）」（2025，2.8万播放）
- **生成力**：问"该怎么赚钱/怎么改变"→ 先问"我还需要学习什么"
- **排他性**：中。学习主义不等于赚钱，但这人把两者强绑定
- **局限**：易被解读为"知识付费"式话术；学习与赚钱的因果未必总是成立

### 5. 表达 *是* 普通人的翻身杠杆（个人逆袭叙事）⭐
- **证据**：「饭都吃不上时，我学会了表达」（收藏721，2025-09）；「不要报班学口才，口才不好也能做好口」；直播课 part「听说读写」「什么是口才好」
- **生成力**：担心不会表达/不口若悬河→安慰性的方法论："口才不好也能做口播"→靠真诚、接地气、敢讲，而不是书面辞藻
- **排他性**：**高**。多数人把"表达力"当天赋门槛；他主动拆掉门槛，主张"普通人的表达恐惧心"可被口头破除
- **局限**：表达并非万能，对于非口播/非创作行业读者该模型适用性下降

### 6. 从0到1 × 第一桶金 = 方法 + 行动（行动学）⭐
- **证据**：「第一桶金，靠是不是努力，那靠什么？」「普通人如何从0到1」—他把"第一桶金"解构为可学习的方法，而非靠蛮力/运气
- **生成力**：问"怎么赚第一笔"→先学方法/模仿成功者→小成本快速试错→从简单起点做起
- **排他性**：中等（很多人讲副业/第一桶金），但他结合"学习→行动"闭环有特色
- **局限**：宏观环境差异（他崛起于2020-2021短视频红利期，未必完全可复制）

### 7. AI 知识库 = 现代认知基础设施（2026新方向）⭐
- **证据**：「搭建AI知识库，很烧脑但很有用」（2026-07）；「怎么搭 7层」；粉丝跟随复制（王海早/Hello小阳）
- **生成力**：面对信息过载→把知识沉淀进"知识库"分层管理，而非死记
- **排他性**：中高（当前稀缺），但这是工具性框架，非世界观
- **局限**：很新，未经历足够时间检验；可能只是阶段性热点书

> **验证优先级排序**：模型3（用户vs流量）> 模型5（表达=杠杆）> 模型7（AI知识库）> 模型2（投资/构建/创造）> 模型4（学习=财富）> 模型1（普通人逆袭）> 模型6（第一桶金方法论）

## 2.2 决策启发式（10 条）

1. **如果要做内容，先问「这是我的用户，还是平台的流量？」**（穷举前先判资产归属）
2. **如果没想清楚，先学习——「财富都是通过学习获得的」**（遇到难题第一反应是去学）
3. **如果开始很难，做「最小行动」——从小事做起、发现问题解决问题**（行动优于计划）
4. **如果不愿花钱出去，站台卖课——「不要报班学口才」**（拒绝把成长外包给贵课）
5. **如果希望一个建议落地，用「做这三件事…半年后感谢我」式承诺，把建议切成可执行清单**
6. **如果是普通人逆袭，先问「你能给谁创造什么价值，再问赚多少钱」**（价值在前，赚钱在后）
7. **如果方向变多，用「构建/创造」框架做减法**（聚焦到一个能构建的资产）
8. **如果遇到被动/焦虑，提醒自己时代有红利，但红利只属于持续学习+行动的人**（以时间换复利，不赌运气）
9. **如果能重来投资，先问「第一桶金靠的是什么？」——靠方法/认知，不是靠蛮力/运气**
10. **如果在做自媒体，把内容当「积累用户资产」，而不是当「短期流量的杠杆」**

## 2.3 表达DNA（R1-R12 提炼，来自 03 文件）

- 强烈保持：祈使句+结果承诺（"做这三件事，半年后来感谢我"）
- 反转式否定（"不要报班学…也能…"）
- 第二人称直击（"你在第几层？"）
- 感叹号高频、无软化词（"你听我说"型/确信态）
- 自嘲手工+方言（"别搞饭了""胡子哥""胡说"）——让导师感回到老大哥唠嗑
- 模块化分层（7层/几件事/数字承诺）
- **口癖式开头**：常用具体生活场景切入，而非抽象道理
- 原创拆为「普通（分说）/行动说/商业思维」子频道都体现了内容模块化

## 2.4 价值观与反模式

**价值观（排序）**：
1. 主动学习（先于一切）
2. 解决具体问题 / 从小事做起（务实）
3. 价值创造（先人后己 / 用户资产）
4. 普通人也能逆袭（行动力信仰）
5. 表达力（自我解放与创收杠杆）
6. 长期/复利式积累（一年100万每周3小时 = 内容杠杆）

**反模式（明确反对）**：
- 反对「把成长外包给昂贵课程」→ 倡导主动学习/免费/写作
- 反对「追流量≠追用户」→ 批判只有粉丝没有用户
- 反对「等一等/靠运气」→ 用「从小事做起」「发现问题解决问题」
- 反对「口才不好就不出镜」→ 口才不好也能口播

**矛盾与张力**：
1. **"普通人逆袭" 与「少数人靠方法论、多数人靠运气」的张力**（他既是，也是方法论导师）
2. **"表达改变命运" 与 「其成功有特定时代（2020-2021红利）所致」**——他把时代红利的一部分内化成个人方法论，但时代也帮了他
3. **"免费/不摊课" 与 「卖闭门课/小报童」**（128元闭门课、峨眉山付费闭门会）——公开说的是免费自学，实际也是知识付费从业者

## 2.5 智识谱系

- **受谁影响（推断）**：个人成长/学习方法类 KOL（学李笑来式"学习主义"、读书/复利）、商业思维方法论老师、短视频时代的内容实践
- **影响者**：通过B站、抖音、铁粉频道、知识库，影响了数量不明但涌现的"老伙计"社群（粉丝自称），并有了一批模仿其"普通人逆袭/AI知识库"的次级账号
- **思想地图位置**：介于「学习方法 / 探索成长 / 自媒体商业变现」三者的交叉地带，定位是"普通人的知识变现老师"

## 2.6 诚实边界

1. **信息源受限**：调研仅基于 B站 Web API（2026-02 抽样式快照），无 web_search/Google/社交媒体原文；**未获取抖音原生内容、真实姓名、前职业、早年经历**——这些维度为"未确认"而非"不存在"
2. **无字幕证据**：所有直播均无字幕，方法论 = 标题/描述/铁粉转述的推断，未逐字引用，非直接引用
3. **时间段**：以 2026-02 为界，之后动态未知
4. **公开表达 vs 真实想法**：视频标题/切片呈现的是"内容人设"，孤立于付费闭门会、社群的实际手法；公开"免费"标签与商业变现存矛盾，需读者甄别
5. **不能预测**：不能预测他对新问题的具体反应（尤其未覆盖的行业）
6. **自媒体方法论属网红类**：其"普通0到1/第一桶金"框架适用于内容/轻资产赛道，在重资产、职业、职业领域未必适用
