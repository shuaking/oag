# 调研方法与可信度说明（本次重建：2026-09-29）

本文件记录本次「李笑来 perspective」Skill 重建的**调研条件、证据分级规则与已知限制**。
它存在的目的是让使用者知道：**哪些结论是硬证据，哪些只是标题级线索。**

---

## 一、本次调研的取证条件（关键）

### 1.1 工具状态（2026-09-29 实测）

| 能力 | 状态 | 说明 |
|------|------|------|
| `web_search` | ✅ 可用 | 搜索结果标题、来源 URL，偶尔返回 summary answer 摘要 |
| `web_fetch`（内置抓取） | ❌ **全局不可用** | 对任何站点（含 wikipedia、36kr、百度）均返回 `resolves to a non-public IP address` |
| PowerShell 直接出网 | ❌ 不可用 | DNS 被劫持到 198.18.x.x；schannel 取不到沙箱凭证（`SEC_E_NO_CREDENTIALS`） |
| **本机 HTTP 代理（127.0.0.1:7890）** | ✅ **可用** | 经 Node 的 `http CONNECT` + `tls` 隧道可正常出网并抓取网页正文 |

**结论：本次调研可以阅读网页正文，但必须走本地代理通道**，脚本为
`.tmp-fetch/lxl-batch.mjs`（UTF-8 解码 + HTML 转文本）与 `.tmp-fetch/crawl.mjs`（站点批量爬取）。

> **方法学教训（值得记录）**：调研初期我（父 Agent）基于 `web_fetch` 与裸 PowerShell 的双重失败，
> 过早得出"无法获取正文"的结论，并据此向全部 6 个 Agent 下达了"只用标题、放弃正文"的指令。
> 是 Agent 1 与 Agent 2 独立探测到本地代理，才纠正了这一错误判断。
> **教训：工具失败不等于能力缺失；把"某个工具坏了"等同于"这件事做不到"，会人为压低整个项目的质量上限。**

### 1.2 抓取覆盖度

- **可抓**：新浪、网易、界面、搜狐、腾讯新闻、钛媒体、南方周末、新京报、凤凰网、财新（部分）、
  GitHub / GitHub raw、小宇宙、B站、文轩网、当当、微信读书页、人民论坛等。
- **抓不到**（WAF/验证码/403）：虎嗅（阿里云 WAF）、36氪、豆瓣、雪球、Bloomberg / SCMP / investing.com。

### 1.3 与旧版（2026-04）的对比

旧版的问题不是"没抓正文"，而是**根本没有检索**——它基于 AI 训练语料直接生成，却把推测写成了事实，
甚至虚构了引语与媒体标题（已核出至少 5 个不存在的标题、1 个无来源的募资金额）。
本次重建的原则因此是：**证据降级可以接受，虚构绝不接受。**

## 二、证据分级规则（本 Skill 全篇适用）

| 级别 | 定义 | 呈现方式 |
|------|------|---------|
| **A 一手·可溯源** | 本人著作/开源书/本人账号内容，且有可追溯 URL | 正常引用 |
| **B 二手·权威媒体** | 财新/晚点/36氪/界面/南方周末/新京报等，标题或摘要可见 | 注明媒体与 URL |
| **C 标题级** | 仅搜索结果标题支撑，正文未验证 | **必须标注「标题级证据，未验正文」** |
| **D 存疑/无法证实** | 仅见低可信渠道、或仅网络传言、或多源冲突未决 | 标注「存疑」，不得写成事实 |
| **E 推测** | 提炼者的推断 | 显式标注「推测」 |

**铁律**：不得把 C 级证据当作 B 级呈现；不得替原文补写内容、论证或引语。

## 五、本次重建已核出的旧版错误（供使用者对照）

| 旧版说法 | 核验结论 |
|---------|---------|
| 书目止于 2021 年 | **缺漏**：漏掉 2023-2025 年近作（《财富的真相》《思考的真相》《专注的真相》《好的家庭教育》） |
| 「PressOne 募资超 2 亿美元」 | **无任何权威来源**，判为无法证实 |
| 列举的 5 个媒体标题（如"李笑来录音门：币圈大佬割韭菜实录"） | **逐一检索均不存在**，疑似编造 |
| 「2017 参与 EOS 超级节点竞选」 | 方向有误；真实情况为 EOS 官方"去李笑来化"切割他 |
| 「学习就像健身，不是知道方法就行，得真练」等"即兴类比" | **查无实据**，疑似生成而非实录 |
| 他被描述为纯粹的"被告/骗子"形象 | **结构性错误**：他至今无监管点名、无行政处罚、无刑事认定；且作为原告在诉陈伟星名誉权案中二审胜诉（名誉权胜诉 ≠ 诈骗指控被证伪，不可过度解读） |

## 六、信息不足的维度（诚实标注）

- **长对话**：无法读到任何访谈正文，只能依赖标题与摘要，粒度最粗。

- **2026 年**：实质性报道近乎为零，难以区分"他静默"与"检索不可达"。
- **个人站点 lixiaolai.com**：解析到非公网 IP，本次完全无法访问。
