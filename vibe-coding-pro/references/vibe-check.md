# ✨ Vibe Check: 氛围优化清单

当用户说“UI 比较丑”或“感觉不对”时，请对照此清单进行自我审查。

## 1. 视觉平衡 (Visuals)
- [ ] **间距 (Spacing)**: 所有的元素是否遵循 8px 网格系统？是否存在拥挤感？
- [ ] **排版 (Typography)**: 标题与正文的层级是否明显？行高是否舒适？
- [ ] **一致性 (Consistency)**: 所有的按钮圆角、边框粗细是否统一？

## 2. 交互反馈 (Feedback)
- [ ] **状态 (States)**: 点击按钮是否有 Loading 状态？操作成功是否有 Toast 提示？
- [ ] **动效 (Motion)**: 进入页面是否有简单的渐入动画？切换是否生硬？

## 3. 内容表达 (Copywriting)
- [ ] **文案**: 提示信息是否友好？是否包含“AI 味”的废话？

## 4. 优化动作 (Action)
- [ ] 调用 `ui-ux-pro-max` 重新生成配色方案。
- [ ] 使用 `frontend-design` 优化复杂的列表或表单布局。
- [ ] 更新 `SKILL.md` 记录本次优化发现的模式。
