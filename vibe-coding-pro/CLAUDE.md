# 🎮 Vibe Coding Pro (Claude Edition)

This document provides the standard operating procedure for **Vibe Coding** in Claude Projects or Custom Instructions.

## 🚀 Core Commands & Workflow

### 1. `/vibe-plan` (Vibe to Spec)
- **Objective**: Convert fuzzy ideas into `docs/specs/`.
- **Tools to use**: Knowledge retrieval, Architectural analysis.
- **Workflow**: 
  1. Research tech docs.
  2. Simulate expert review.
  3. Generate SPEC using the template in `references/spec-template.md`.

### 2. `/vibe-exec` (Vibe Execution)
- **Objective**: Transform SPECs into `docs/plans/` and execute coding.
- **Workflow**:
  1. Record persistent plan.
  2. Implement features via sub-agent driven development.

### 3. `/vibe-fix` (Vibe Systematic Fixing)
- **Objective**: 4-stage systematic debugging.
- **Workflow**:
  1. Reproduce.
  2. Diagnose.
  3. Fix.
  4. Simplify and refactor code.

### 4. `/vibe-check` (Vibe Aesthetic Polish)
- **Objective**: Elevate UI/UX to production-grade.
- **Workflow**:
  1. Define high-fidelity UI spec.
  2. Implement with polished CSS/animations.
